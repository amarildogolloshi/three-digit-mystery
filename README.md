# 🔐 Unlock the Vault

A fun puzzle game built with **HTML, CSS, and Vanilla JavaScript**.

Players must crack a secret 3-digit vault code using clues and logic. Each game generates a new random code, and additional hints are revealed after incorrect guesses.

## 🎮 Play Online6 7Try the game here:8 9👉 **[Play Three-Digit Mystery](https://amarildogolloshi.github.io/three-digit-mystery/)**

## 🎮 How to Play

1. Read the available clues.
2. Use the lock wheels to select a 3-digit combination.
3. Click **Unlock Vault**.
4. If the code is incorrect, you will receive feedback:
   - ✅ Digits in the correct position
   - 🔄 Correct digits in the wrong position
5. After every incorrect attempt, a new hint is unlocked.
6. Unlock the vault before your friends beat your time!

## 🧩 Hint Examples

The game can generate clues such as:

- The first digit is odd.
- The digits add up to 15.
- The largest digit is 8.
- There are 2 digits greater than 5.
- The first and second digits add up to 10.

New hints are revealed after each incorrect guess.
