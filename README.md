# three-digit-mystery


The game:

Generates a random 3-digit code with no duplicate digits
Creates hints automatically
Lets the player enter guesses
Counts attempts
Supports "New Game"
Displays a success message when solved

Future Enhancements
You could make it much more interesting by:

Randomly generating a new code every game
Generating clues automatically
Adding difficulty levels (Easy, Medium, Hard)
Adding a timer
Giving only 5 attempts
Adding a treasure chest image that opens when solved
Tracking score and best time

You can make it even more fun by adding:
